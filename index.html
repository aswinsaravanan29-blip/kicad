System Architecture

The VARUNA06 is a compact, modular underwater sensor node designed for ROV-mounted seafloor mineral and metal detection. It acquires multi-sensor electromagnetic response signatures for downstream signal processing and classification.

Key Specifications

  • Board: 85mm × 55mm, 2-layer FR4
  • MCU: STM32L476RGT6 (ARM Cortex-M4)
  • Precision ADC: ADS1256 (24-bit, 30kSPS)
  • EM Sensing: Coil driver + LNA + ADC
  • Pressure: MS5837-30BA (0-30bar)
  • Temperature: Dual PT1000 + TMP117
  • IMU: ICM-20948 (9-axis)
  • Comms: RS-485 half-duplex
  • Power: 9-24V input, 3.3V/5V rails
  • Protection: ESD, reverse-polarity, OCP

Design Notes

  • Separate analog/digital ground zones
  • Star ground at ADC GND
  • Guard rings on sensitive traces
  • 4× M2.5 mounting holes
  • SubConn-compatible connectors
  • Operating depth: 0-300m rated
  • Data provided for post-processing classification

    Power Nets

    • VIN — Raw input 9-24V
    • V5P0 — 5V regulated (sensor/analog)
    • V3P3 — 3.3V regulated (MCU/digital)
    • AGND — Analog ground plane
    • DGND — Digital ground plane

    Analog Signal Nets

    • EM_COIL_DRV — EM coil drive signal
    • EM_COIL_SENSE — EM pickup sense
    • EM_LNA_OUT — LNA output
    • EM_BPF_OUT — Bandpass filter out
    • EM_PGA_OUT — PGA output to ADC
    • PRESSURE_IN — Pressure sensor analog
    • TEMP1_IN, TEMP2_IN — PT1000 inputs
    • ADC_MISO, ADC_MOSI, ADC_SCLK, ADC_CS

    Digital / Communication Nets

    • I2C_SCL, I2C_SDA — IMU, Pressure bus
    • SPI bus — ADS1256 interface
    • UART_TX, UART_RX — Debug console
    • RS485_A, RS485_B — Differential comm
    • RS485_DE, RS485_RE — Direction control
    • LED_GRN, LED_RED, LED_BLU — Status
